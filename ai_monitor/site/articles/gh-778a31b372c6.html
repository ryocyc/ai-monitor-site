Mika 18日吸8,723星：Android本機AI代理

內文

Mika 係 Android 手機上嘅 AI 代理，可按指示操作應用程式及網頁完成任務。GitHub 顯示，項目喺 18 日內累積 8,723 個星標（stars），平均每日約 500 個。

佢唔依賴 app API 或專屬整合，會開啟程式、點擊、輸入及捲動，並喺背景畫面運作；內置瀏覽器亦可處理頁面內容。Mika 會記住偏好，把完成嘅任務轉成技能。系統無 Mika 伺服器，模型可經 API 或帳戶連接。

以前要逐個 app 搜尋、點擊及輸入，而家可用語音或文字交代跨 app 工作，例如設定翌日朝早 9:40、10:00 嘅鬧鐘。適合處理重複流程嘅 Android 用戶；登入、驗證碼同付款仍要親自接手。

同類可比較 ChatGPT 等通用 AI 助理；資料未交代其跨 app 自動化細節，可否取代 Mika 未能確認。安裝要配對無線除錯，部分手機可能缺少 helper；改 Wi-Fi 或重啟後控制或會失效。自動操作第三方服務可能違反條款，重要操作應用 Ask mode 覆核。

點解要理

  • 18 日累積 8,723 個星標，平均每日約 500 個。
  • 以背景畫面操作應用程式及網頁，不依賴個別 app API 或專屬整合。
  • 登入、驗證碼及付款交由用戶接手，安裝前須留意無線除錯及服務條款。
