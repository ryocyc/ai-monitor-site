Mika：Android AI 代理代辦應用與網頁任務

Mika 係 Android 手機端 AI 代理，可用自然語言操作應用程式與網頁，並處理定時或重複任務；涉及登入、驗證碼與付款時會交回用戶。

英文搜尋標題:Mika AI Agent for Android

內文

Mika 係面向 Android 嘅手機端 AI 代理，講出目標，佢可操作應用程式及網頁完成任務。示範包括代發訊息；Mika 會開程式、點擊、輸入同捲動，使用者可一邊用手機，點小視窗睇進度。

佢唔靠 App API，會模仿人睇畫面搵按鈕；內置瀏覽器可讀頁。Mika 會記住偏好，將任務變成技能，亦支援定時指示。模型可經 ChatGPT、xAI 或 OpenRouter 帳戶登入，或填 API key；首次須配對無線偵錯。

以前要逐個開 App、搵頁面同輸入，可交畀 Mika，設定翌日朝早九點四十分同十點嘅鬧鐘，或朝早八點查天氣、下雨先通知。適合想用語音交代跨 App 工作嘅 Android 用戶；登入、驗證碼及付款會交回人手。

同類有 Android 自動化工具 Tasker；Mika 以自然語言操作網頁，但部分手機系統或未能提供控制功能。官方提醒，操作第三方服務或違反條款，重要操作應用 Ask 模式並核對結果。內容只送交所選模型供應商；API key 及記憶加密，對話紀錄留喺手機。

點解要理

  • 以自然語言操作 Android 應用程式及網頁，毋須為每個 App 開發整合。
  • 支援瀏覽器、偏好記憶、技能、定時指示及 Ask 模式。
  • 登入、驗證碼與付款交回用戶；模型可選帳戶登入或使用 API key。
