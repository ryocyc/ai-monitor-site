Blender AI MCP 外掛加入視覺聊天與場景工具

Blender AI MCP 為免費開源 3D 軟件加入聊天式 AI 助手，可檢查場景、建模、調整材質、搜尋素材及輸出場景。

英文搜尋標題:Blender MCP

內文

Blender AI MCP 係安裝喺 Blender 嘅 AI 外掛；Blender 係免費開源嘅 3D 軟件。佢加入 AI 助手同 MCP 伺服器，提供視覺對話、場景工具及多代理工作流程。

助手可檢查場景、建模、改材質、搜素材、查 API 及輸出。對話窗整合截圖、審批、任務板與復原；任務依序執行，受阻時修正一次，再失敗即停止。支援 ChatGPT、Claude、Gemini、Ollama、OpenCode 同自訂端點。

以前要逐項點擊建模、改材質或者自行寫 bpy 程式，而家可用自然語言要求製作產品展示佈局、排列物件並查看預覽。藝術家適合加快反覆修改，技術美術可處理重複工序，開發者可將 AI 接入 Blender；多代理模式由管理者、工作者同審查者分工。

同類選擇有可比替代方案 BlenderMCP，差異要按版本核對。外部 MCP 客戶端自行決定審批政策，Python 驗證唔係安全沙盒；安裝前要留意權限、服務金鑰及素材授權。憑證存於使用者設定，對話只留目前工作階段。

點解要理

  • 以視覺聊天檢查場景、建模、改材質、搜尋素材及輸出場景
  • 內建任務板、操作審批、復原步驟及依序執行機制
  • 支援多種模型端點與多代理分工流程
