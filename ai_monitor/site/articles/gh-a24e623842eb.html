Yogurt 五日吸 1,655 個 GitHub 星標

FrigadeHQ 的跨平台開源工具，以本機模型完成轉錄、摘要與問答，並可接駁 AI 助理的 MCP。

英文搜尋標題:Yogurt Notes

內文

Yogurt 是開源 AI 會議筆記軟件，讓資料留在本機，定位為 Granola 的免費替代品。GitHub 顯示，它 5 日獲 1,655 個 stars，日均約 316 個。

支援 macOS、Windows、Linux。首次約下載 5 GB 小型筆記模型，再按硬件選合適模型，部分達 14 GB 或以上；轉錄用 Whisper，摘要及問答以 llama.cpp 跑本機模型。只為模型下載及更新檢查上網，毋須帳戶。

它能在任何程式錄下咪高峰與系統聲音，偵測 Zoom、Teams、Meet 通話後由用戶決定是否錄音。下載模型後，筆記與問答可離線使用。開發者可將 Yogurt 接成本機 MCP 伺服器，讓 AI 助理唯讀查閱會議內容。

同類有 Granola；Otter、Fireflies 能否離線，材料無法確認。Yogurt 不派機械人加入會議，錄音前須告知其他人。MCP 存取預設關閉；開啟後，同一帳戶下任何應用程式均可讀取內容，且可能把資料送到自己的線上模型，不使用時應關閉。

點解要理

  • 5 日累積 1,655 個 GitHub stars，平均每日約 316 個
  • 轉錄與摘要在本機處理，筆記及問答可離線使用
  • 支援 macOS、Windows、Linux，並可讓 AI 助理透過本機 MCP 唯讀存取

來源

資料來自 GitHub Search 與 FrigadeHQ/yogurt 專案頁；功能及限制按頁面整理，stars 數按題述 5 日統計，未有獨立活躍用戶數據。
